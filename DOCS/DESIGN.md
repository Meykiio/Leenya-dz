# Leenya Design System

## Design Philosophy

Leenya follows a **clean, whitespace-forward** interface with a **purple accent** (`--accent: hsl(260 97% 61%)`). The result is an ultra-clean, whitespace-forward interface that feels hand-crafted — not generated by AI. Every pixel is intentional. Nothing is decorative.

**Core principles:**
- **Precision over decoration.** Every element earns its place.
- **Whitespace is a feature.** Content breathes. Nothing feels cramped.
- **Hierarchy through weight & spacing**, not color alone.
- **Light mode only** — dark mode CSS variables exist but are NOT implemented. No dark mode toggle exists.
- **No AI tells:** No gradient text, no neon glows, no generic 3-column card grids, no glassmorphism as default, no hero-metric templates.

## Typography

### Font Stack

| Role | Font | Fallback |
|------|------|----------|
| Body/Headings | **Sora** (variable) | `system-ui, -apple-system, sans-serif` |
| Code/Data | **JetBrains Mono** (variable) | `ui-monospace, monospace` |
| Arabic | **IBM Plex Sans Arabic** | `sans-serif` |

### Type Scale

| Name | Size | Line Height | Letter Spacing | Usage |
|------|------|-------------|-----------------|-------|
| `text-xs` | 11px | 1.45 | 0.01em | Labels, badges |
| `text-sm` | 13px | 1.5 | — | Meta, sidebar nav |
| `text-base` | 15px | 1.6 | — | Body text |
| `text-lg` | 17px | 1.5 | — | Intro paragraphs |
| `text-xl` | 20px | 1.4 | — | Section subtitles |
| `text-2xl` | 24px | 1.3 | -0.01em | Section headings |
| `text-3xl` | 30px | 1.2 | -0.02em | Page headings |
| `text-4xl` | 38px | 1.1 | -0.02em | Hero headings |
| `text-5xl` | 48px | 1.05 | -0.03em | Display headings |

### Typography Rules

- Body line length capped at 65–75ch
- Weights: Regular (400) for body, Medium (500) for labels, Semibold (600) for headings
- Never use all-caps body copy. Reserve uppercase for short labels (≤4 words)
- `text-wrap: balance` on h1–h3 for even line lengths
- No font-family count > 3 (Geist + Geist Mono + IBM Plex Sans Arabic)

## Spacing

- **4px base unit** (mapped to Tailwind's standard spacing scale)
- Section gaps: `space-y-6` (24px) between related groups, `space-y-10` (40px) between sections
- Card padding: `p-4` (16px) to `p-6` (24px)
- Page horizontal padding: `px-4 lg:px-6`
- Dashboard sidebar width: 220px (`w-[220px]`)
- Use negative space over borders for visual separation

### Dashboard Layout

```
┌──────────────────────────────────────────────┐
│                                                │
│  ┌─────────┐  ┌────────────────────────────┐  │
│  │         │  │  Top Bar (50px)            │  │

│  │ 220px   │  │                             │  │
│  │         │  │  Main Content               │  │
│  │ Fixed   │  │  (Suspense-wrapped)         │  │
│  │         │  │                             │  │
│  │         │  │  Whitespace on both sides   │  │
│  └─────────┘  └────────────────────────────┘  │
│                                                │
└──────────────────────────────────────────────┘
```

### Rules
- **No max-width constraints** on dashboard pages (content should fill available space naturally)
- Public pages: `max-w-7xl mx-auto` for centering
- Settings can use `max-w-3xl` only if form-heavy and readability benefits from shorter line lengths — apply per-section, not to the outer shell
- **Grid over flex-math:** Use CSS Grid (`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6`) instead of complex flexbox percentage math
- **No h-screen:** Use `min-h-[100dvh]` for full-height containers

## Component Patterns

### Cards
- Use only when elevation communicates hierarchy
- Default card: `bg-card text-card-foreground rounded-lg border shadow-xs p-4`
- **No nested cards** — always wrong
- Prefer `border-t` + `divide-y` over card containers for data grouping when `VISUAL_DENSITY > 4`

### Buttons
- Primary: `bg-primary text-primary-foreground hover:bg-primary/90`
- Secondary: `bg-secondary text-secondary-foreground hover:bg-secondary/80`
- Ghost: `hover:bg-muted hover:text-foreground`
- Label: verb + object ("Save changes" beats "OK")
- Active state: `translate-y-[0.5px]` or `scale-[0.98]`

### Forms
- Labels above inputs (`gap-2`)
- Helper text optional but in markup
- Errors below input
- Touch targets ≥ 44px

### Navigation
- Sidebar: 220px fixed, uses `--bg-subtle` background
- Active state: `--accent-light` bg + `--accent` text color
- Mobile: `lg:hidden` bottom nav (max 5 items)
- Desktop sidebar stays mounted — no remounting on navigation

| Token | Value | Usage |
|-------|-------|-------|
| `--shadow-xs` | `0 1px 2px rgba(12,12,10,0.04)` | Subtle card |
| `--shadow-sm` | `0 1px 3px rgba(12,12,10,0.06)` | Card hover |

| `--shadow-lg` | `0 8px 24px rgba(12,12,10,0.06)` | Modal, drawer |

Shadows are tinted to the neutral base hue — never pure black.

## Motion

- Duration: 150–250ms for micro-interactions
- Easing: `cubic-bezier(0.16, 1, 0.3, 1)` — exponential ease-out
- Transform only (no animating width/height/top/left)
- Reduced motion: `@media (prefers-reduced-motion: reduce)` respected
- Spring physics for interactive elements: `type: "spring", stiffness: 100, damping: 20`
- Exit animations faster than enter (60–70% duration)

---

## Dark Mode

- Toggled via `.dark` class on `<html>` element
- Uses `next-themes` (already integrated)
- Linear Purple accent is lighter on dark (`#8780F8` vs `#6B63F6`)
- Backgrounds are never pure black — use `#0C0C0A` base
- Shadows reduce/eliminate on dark (ambient light is from UI, not environment)
- All components tested in both modes independently

## Anti-Patterns (DO NOT USE)

- ❌ Purple/blue neon glows ("AI aesthetic")
- ❌ Gradient text (`background-clip: text`)
- ❌ Glassmorphism as default UI (blurs used decoratively)
- ❌ Generic 3-column card grids (icon + heading + text repeated)
- ❌ Hero-metric template (big number + small label + stats)
- ❌ Side-stripe borders (`border-left`/`border-right` > 1px as accent)
- ❌ Emojis as icons (use Lucide or Radix icons)
- ❌ Inter font (use Sora)
- ❌ Pure black (`#000000`) — use `#0C0C0A`
- ❌ Oversized H1s (hierarchy through weight + color, not just scale)
- ❌ Custom mouse cursors
- ❌ Section markers (01 / 02 / 03)
- ❌ Tiny uppercase tracked eyebrow above every section
- ❌ "Elevate", "Seamless", "Unleash", "Next-Gen" in copy

## Multi-language Support (Implemented)

- **react-i18next** + `i18next-browser-languagedetector` + `i18next-http-backend`
- **Status:** Done — all ~60+ components use `t()` calls. ~590 keys per locale. 6 namespaces × 3 languages.
- **Default:** French (Algeria)
- **Languages:** French (fr), Arabic (ar), English (en)
- **Translation files:** `public/locales/{fr,ar,en}/{namespace}.json`
- **Namespaces:** `common`, `dashboard`, `booking`, `queue`, `staff`, `landing`
- **Language switcher:** In navbar on landing page, in footer on other pages
- **Arabic:** RTL layout via `dir="rtl"`, mirrored spacing (`ms-*` / `me-*`), flipped icons. All 35+ components RTL-patched.
- **Arabic font:** IBM Plex Sans Arabic (loaded via Google Fonts)
- **Key files:** `src/i18n/index.ts`, `src/hooks/useLanguage.ts`, Tailwind config with `rtl:` variant
